# SMM-бот для Instagram: итоги Discovery и план MVP

_Версия 1.0 · 27.11.2026_

## 1. Суть продукта

Telegram-бот, через который клиент заказывает накрутку в Instagram: подписчики, лайки, просмотры, комментарии.
Бот проводит клиента по шагам, считает сумму, принимает оплату и передаёт заявку команде.
Команда (владелец и 2 сотрудника) выполняет заказы вручную.

Референс по услугам и ценам: firezup.com. Наши цены = цена firezup со скидкой × 1.5.

| Параметр | Решение |
|---|---|
| Клиенты | Частные лица и компании, до 10 на старте |
| Соцсети | Только Instagram |
| Выполнение заказов | Вручную, сотрудник команды |
| Языки бота | Русский, украинский, английский (выбор при старте) |
| Валюта | USD |
| Оплата | 1) перевод на карту (основной), 2) крипта USDT через Crypto Bot |
| Срок доставки | Постепенно, как у референса (большие заказы до нескольких дней) |
| Гарантия восполнения | 30 дней |
| Запуск | Выходные 28–29.11.2026 |
| Бюджет на инфраструктуру | до $10 в месяц |

### Сценарий клиента

1. `/start` → выбор языка (RU / UA / EN).
2. Выбор услуги (кнопки).
3. Выбор пакета (кнопки с количеством и ценой).
4. «Добавить ещё услугу?» → Да (возврат к шагу 2) / Нет.
5. Корзина: список услуг и итоговая сумма. Можно удалить позицию.
6. Ввод ника Instagram (бот проверяет формат).
7. Для каждой услуги, привязанной к посту, ввод ссылки (бот проверяет: `instagram.com/p/…`, `/reel/…`, `/tv/…`).
8. Для комментариев: пожелания (необязательно).
9. Напоминание: аккаунт должен быть открытым. Подтверждение заказа.
10. Выбор оплаты:
    - **Карта:** бот показывает номер карты и сумму, клиент переводит и присылает скриншот или квитанцию.
    - **Крипта:** бот выставляет счёт в Crypto Bot, оплата подтверждается автоматически.
11. Статусы приходят клиенту: «оплата подтверждена» → «в работе» → «выполнено».
12. «Мои заказы»: история и статусы. «Поддержка»: связь с менеджером.

### Сценарий команды

- Все заявки приходят в **закрытую Telegram-группу команды**.
- Карточка заказа: номер, клиент, услуги, ник и ссылки, сумма, способ оплаты, скриншот оплаты.
- Кнопки: **Оплата подтверждена / Отклонить** (для карты), **Взять в работу**, **Выполнено**, **Отменить**.
- Нажимать кнопки могут только 3 человека из белого списка.
- Каждое действие записывается: кто и когда нажал.

## 3. Не входит в MVP (версия 2 и дальше)

- Месячный план (подписка с конструктором).
- Telegram Stars (оплата Apple Pay / картой внутри Telegram).
- Промокоды и скидки.
- Другие соцсети (TikTok, YouTube, Facebook…).
- Автоматическая передача заказов оптовой SMM-панели через API.
- Админ-панель в самом боте (правка цен командами), статистика продаж.

## 4. Архитектура

```
Клиент (Telegram) ──► Telegram API ◄── Бот (Python, Railway, 24/7)
                                           │
                     ┌─────────────────────┼──────────────────────┐
                     ▼                     ▼                      ▼
             Supabase Postgres      Crypto Pay API         Группа команды
         (услуги, цены, заказы,   (счета USDT, проверка    (карточки заказов,
          клиенты, журнал)          статуса оплаты)          кнопки статусов)
```

| Компонент | Технология | Почему |
|---|---|---|
| Бот | Python 3.12 + aiogram 3 | Самая распространённая библиотека для Telegram-ботов, быстро писать |
| Связь с Telegram | Long polling | Не нужен публичный адрес: меньше поверхность атаки и проще запуск |
| Хостинг | Railway (уже оплачен) | Деплой из GitHub, автоперезапуск при сбое |
| База данных | Supabase Postgres (уже оплачен) | Бэкапы, веб-редактор таблиц для цен |
| Крипта | Crypto Pay API (@CryptoBot) | Автоматическое подтверждение, комиссия около 3% |
| Код | GitHub, папка `smm-bot/` | История изменений, деплой на Railway |

### Модель данных (кратко)

- `services`: услуга, тип ввода (ник или ссылка), названия на 3 языках, вкл/выкл.
- `packages`: услуга, количество, цена в USD, вкл/выкл.
- `customers`: Telegram ID, имя, язык.
- `orders`: номер, клиент, ник, сумма, способ оплаты, статус, время.
- `order_items`: заказ, пакет, количество, цена **на момент заказа**, ссылка, пожелания.
- `order_events`: журнал: кто, когда, какой статус поставил.
- `settings`: номер карты для перевода, текст поддержки.

Статусы заказа: `ожидает оплаты → оплата на проверке → оплачен → в работе → выполнен`, плюс `отменён` и `отклонён`.

## 5. Безопасность

1. **Секреты** (токен бота, токен Crypto Pay, доступ к БД) хранятся только в переменных Railway. В коде и на GitHub их нет. Владелец вводит их сам, в чат не отправляет.
2. **Пароль от Instagram никогда не спрашиваем.** Бот прямо пишет об этом клиенту.
3. **Доступ команды** проверяется по белому списку Telegram ID. Посторонний не может нажать «Подтвердить оплату», даже если попадёт в группу.
4. **Цена считается только на сервере** из базы. Подменить сумму клиент не может. Цена фиксируется в заказе на момент оформления.
5. **Крипто-оплата** проверяется запросом к Crypto Pay. Словам клиента («я оплатил») бот не верит.
6. **Карта:** оплату подтверждает только человек из белого списка. Повторное подтверждение невозможно.
7. **Проверка ввода:** формат ника и ссылок, ограничение длины, защита от флуда.
8. **База данных:** включён RLS, публичного доступа к таблицам нет, бот ходит под отдельной ролью.
9. **Минимум личных данных:** храним только Telegram ID, имя, язык и ник Instagram.
10. **Бэкапы:** ежедневные, средствами Supabase.

## 6. Риски и как их снижаем

| Риск | Влияние | Что делаем |
|---|---|---|
| Банк задаёт вопросы из-за частых поступлений на карту | Временная блокировка карты | Небольшие объёмы на старте. Отдельная карта под бизнес. Позже ФОП или эквайринг в Армении |
| Правила Telegram требуют Stars для цифровых услуг | Бота могут ограничить по жалобе | Stars в версии 2. Клиенты хранятся в базе, при необходимости переезжаем на нового бота за 10 минут |
| Instagram удаляет часть накрученных подписчиков | Недовольство клиента | Гарантия восполнения 30 дней |
| Сотрудник не успевает выполнять заказы | Задержки | Статусы и журнал. В версии 2 автоматизация через API оптовой панели |

## 8. Что нужно от владельца

1. Создать бота в @BotFather и вставить токен в переменные Railway (пришлю инструкцию).
2. Создать приложение в @CryptoBot → Crypto Pay и вставить токен туда же.
3. Создать закрытую группу команды и добавить в неё бота.
4. Прислать Telegram ID свой и двух сотрудников (это не секрет).
5. Вписать номер карты для переводов в таблицу `settings`.
6. Решить, куда ставить базу: в существующий проект Supabase (отдельная схема, $0) или в новый (около $10 в месяц).
